# Alternative learner and calibration protocol

The user authorized further training and requested a project explanation afterward. Earlier runs found small XGBoost gains, an accuracy tradeoff, and only a small improvement in outcome-free peer means. This experiment tests a different learning implementation and calibration instead of repeating the same grid.

1. Preserve the supplied series partitions. Exclude original test observations from all fitting and prediction. Reuse the same three expanding original-training folds as the previous player search. Every split uses whole series timestamps.
2. Screen six scikit-learn histogram gradient boosting classifiers: expanded and expanded-plus-context features, each with three leaf/regularization recipes. Native categorical splits use an encoder fitted only on the relevant training window; unknown categories become missing values. No player/team identifiers, teammate statistics, final team scores, or outcome labels enter the feature matrix.
3. Inside each training window, use its last 15% of series for chronological early stopping, then refit with the chosen iteration count on the complete window. Refit the best two new configurations on original training. Keep the existing saved XGBoost ensemble as the benchmark.
4. Predeclare candidate probability groups: the existing ensemble, each new finalist, and mixtures containing 25% or 50% of each new finalist with the existing ensemble. These are mixtures of probabilities, not log-odds.
5. Divide the original 480-series selection segment chronologically in half. Fit calibration on the first half and choose the group/calibration combination by log loss on the second. Compare identity, temperature, sigmoid (positive slope plus intercept), and isotonic calibration. The sigmoid's positive slope preserves score ordering. No threshold is tuned to improve diagnostic accuracy.
6. Freeze the chosen group, weights, and calibration family. Refit its calibrator on the separate original 238-series calibration segment. Compare once on the same 243-series diagnostic segment with the actual frozen previous ensemble. Report log loss, Brier, AUC, fixed-0.5 accuracy, series-bootstrap differences, map/agent/patch/length slices, and any regressions.
7. Verify source/artifact hashes, reload all saved predictions, test unseen categories and chronological splits, and audit explanations for the selected candidate. Retain the incumbent if it wins selection; never force a replacement because more training was requested.

**All validation segments have been inspected in earlier research. These are development comparisons, not an independent new test or proof of individual causal impact.** Stop after this fixed search, preserve negative findings, and summarize the full project's behavior and remaining gaps. Research artifacts do not automatically activate in the application.

Existing pinned scikit-learn 1.7.2 supports [explicit early-stopping validation data](https://scikit-learn.org/1.7/modules/generated/sklearn.ensemble.HistGradientBoostingClassifier.html). Calibration choices follow the [official calibration documentation](https://scikit-learn.org/1.7/modules/calibration.html), with independent fit/selection segments within this development protocol.
